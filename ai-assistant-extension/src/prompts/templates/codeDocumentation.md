## Documentation Focus

- Purpose: What the code does and why it exists
- Usage: How to use the code properly
- Parameters: What each parameter means and its constraints
- Returns: What values are returned and what they represent
- Exceptions: What exceptions might be thrown and under what conditions
- Examples: Simple examples of proper usage
