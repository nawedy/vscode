# Change Log

All notable changes to the "AI Assistant" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.0.0] - 2023-06-15

### Added

- Initial release of AI Assistant extension
- Interactive AI response panels that can generate code and explanations
- Support for streaming responses with real-time updates
- Copy to clipboard and insert at cursor functionality
- Token usage tracking and management
- Configuration options for customizing the assistant behavior
- Comprehensive error handling and logging
- Security features including content security policy implementation

## [0.9.0] - 2023-05-30

### Added

- Beta release for internal testing
- Core functionality for AI response generation
- Basic UI components
- Initial test coverage

## [Unreleased]

### Added

- Initial implementation of the AI Assistant extension.

- Telemetry service for usage analytics.
- Configuration service for customizable user settings.
- UI components for displaying AI suggestions and chat interface.

### Changed

- Updated project structure for better organization of files and components.
- Enhanced logging utilities for improved debugging.

### Fixed

- Fixed bugs related to inline suggestions not displaying correctly.
